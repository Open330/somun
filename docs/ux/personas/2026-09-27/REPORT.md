# 페르소나 기반 사용 흐름 검증

2026-09-27 · 대상 커밋 `0e80132da047e0e1ec630f985e9749c136e6e5d7`

실제 로컬 웹 앱을 Chromium으로 조작하여 세 페르소나의 14개 단계를 실행했다. 모두 완료했지만, 다국어 검토 진입에는 수동 언어 전환이 필요했다. 실제 사용자 인터뷰 결과가 아니라 가상의 사용자 목표를 브라우저에서 실행한 검증이다.

## 페르소나와 완료 조건

완료 여부는 화면의 성공 상태와 실제 SQLite 기록으로 검사했다. 민서의 복사는 브라우저 클립보드까지 확인했다. 알렉스는 기존 영어 게시 기록과 한국어 두 버전의 게시 기록이 공존하고, 재작성 후 소개 목적이 유지되는지 확인했다. 지수는 저장 요청 한 번을 실패시켜 입력 보존과 재저장을 확인했다.

## 확인한 개선점

### 1. 검토 링크가 검토할 언어를 열지 않는다 — 우선 수정

재현: X 언어를 EN, KO 순서로 설정 → 영어 초안 게시 기록 → 한국어 소개 초안 생성 → 글감 목록의 ‘초안 검토’ 클릭.

기대: 아직 게시하지 않은 한국어 초안을 연다.

실제: 이미 게시한 영어 화면이 먼저 열린다. KO를 직접 선택하면 검토·게시를 계속할 수 있다. 사용자는 검토할 초안이 사라졌거나 이미 끝난 작업이라고 오해할 수 있다.

화면: [검토 진입 결과](alex-review-entry.png). 관련 코드: `src/web/pages/Candidate.tsx`의 기본 채널·언어 선택, 특히 `curLangs[0]` 기본값.

### 2. 검토 목록과 메뉴 개수 표시가 일치하지 않는다 — 수정 필요

위 상황에서 본문은 ‘검토할 초안 1개’를 표시하지만 왼쪽 글감 메뉴에는 개수 배지가 없다.

메뉴는 `src/web/App.tsx:67`에서 글감 상태가 `drafted`인 경우만 센다. 이미 게시한 글감에 새 미게시 초안이 생긴 경우를 반영하지 못한다. 본문과 같은 검토 대상을 기준으로 표시할 필요가 있다.

화면: [검토 목록과 탐색 메뉴](alex-review-inbox.png).

### 3. 모델 미설정 상태는 생성 요청 후에 드러난다 — 초기 설치 흐름 개선 후보

민서는 모델 키가 없는 새 환경에서 소개글 생성을 요청한 뒤 실패를 확인했다. 오류 화면의 모델 설정 링크로 이동하여 로컬 에이전트로 변경하고 재시도할 수 있었다.

첫 생성 전에 모델 준비 상태를 알려주면 실패를 줄일 수 있다. 단, 이번 조건은 서버 모델 키도 없는 로컬 초기 설치다. 키가 설정된 운영 서비스에서도 같은 문제가 발생한다고 단정하지 않는다. 실제 로컬 에이전트 설치·실행은 이번 검증 범위에 포함하지 않았다.

화면: [모델 실패 안내](minseo-model-failure.png).

## 오류 복구와 화면 검사

- 모바일에서 저장 통신 실패 후 입력 내용이 유지됐다. [실패 안내](jisu-save-error.png)
- 저장 전 EN 전환 시 확인창에서 취소하면 한국어 수정 내용이 유지됐다.
- 재저장 후 게시 기록을 남길 수 있었다. [모바일 게시 결과](jisu-published.png)
- 캡처한 화면에서 문서 전체의 가로 넘침이 없었고, 브라우저의 처리되지 않은 JavaScript 오류도 관찰되지 않았다. 모든 화면·브라우저의 품질을 보장하는 결과는 아니다.

## 실행 환경과 한계

실제 앱의 HTTP API, SQLite 마이그레이션, RSS 수집, 작업 큐의 요청·claim·완료, 수정 및 게시 기록 저장을 사용했다. 각 페르소나는 별도의 메모리 DB에서 실행했다. 생성 결과는 고정된 모의 응답을 작업 큐에 전달했다.

따라서 AI 문장의 사실성·설득력, 실제 모델 연결 및 로컬 CLI 실행, OAuth 로그인, 실제 SNS 게시, 다중 사용자 격리, 장시간 운영은 평가하지 않았다. 게시 링크는 `example.test`의 가상 주소이고 운영 데이터는 변경하지 않았다. 모바일은 데스크톱 Chromium의 화면 크기 재현이며 실기기 검증이 아니다. JSON의 `automationMs`는 자동화 실행 시간으로, 사람의 작업 소요 시간이나 사용성을 나타내지 않는다.

## 재실행

Node 22와 설치된 Chrome이 필요하다. 다른 Chrome 경로는 `CHROME_PATH`로 지정한다.

```sh
npm run build
node scripts/persona-review.mjs
# 한 페르소나만 실행
node scripts/persona-review.mjs alex
```

실행기: [persona-review.mjs](../../../../scripts/persona-review.mjs). 실행 결과: [민서](minseo.json), [알렉스](alex.json), [지수](jisu.json). 실행 실패 시 종료 코드 1을 반환한다. 산출물은 이 폴더에 덮어쓴다.

다음 개선은 검토 진입 언어와 메뉴 개수의 일관성을 우선한다. 그다음 실제 생성 문장과 실제 사용자 관찰을 별도로 평가해야 한다. 이번 작업에서는 평가 실행기와 증거만 추가했으며 제품 코드 수정·배포는 수행하지 않았다.
