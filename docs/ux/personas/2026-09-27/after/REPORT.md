# 페르소나 평가 후 개선 결과

기준 커밋 `0e80132da047e0e1ec630f985e9749c136e6e5d7`에 대한 로컬 작업 트리 변경을 검증했다. JSON의 commit 값은 기준 커밋이며 수정 완료 커밋이나 배포 버전을 의미하지 않는다.

## 변경

- 상세 화면 진입 시 채널·언어별 최신 유효 초안 중 미게시 초안을 우선 선택한다. 이전 버전과 버린 초안은 우선 선택 대상에서 제외한다. 이후 화면 데이터 갱신은 사용자가 직접 선택한 언어를 바꾸지 않는다.
- 글감 메뉴 배지는 목록과 동일한 `stageOf` 기준을 사용한다. 초안 및 게시 기록 변경 이벤트에도 갱신한다.
- 상세 화면에서 생성 전에 모델 키 설정 안내를 표시한다. 설정이 없으면 초안 요청을 큐에 넣지 않고 설정 링크를 안내한다. 서버의 사용 가능한 Gemini 키 구성, 개인 API 키, 로컬 에이전트 선택을 구분한다. 키 설정 여부는 인증 성공·쿼터 여유·로컬 워커 실행을 보장하지 않는다.

## 검증

- 전체 자동 테스트: 51개 파일, 377개 통과.
- 타입 검사, 린트, 프로덕션 빌드 통과.
- 세 페르소나 15단계 통과. 이전의 수동 언어 선택 우회는 제거하고, 올바른 화면 진입을 assertion으로 확인했다.
- 민서: 생성 전 모델 안내를 확인했고, 설정 없이 요청해도 작업 큐가 비어 있었다. 설정 변경 후 소개·편집·복사·게시 기록을 완료했다.
- 알렉스: 메뉴 배지 1을 확인했고, 검토 링크에서 한국어 미게시 초안이 바로 열렸다. 재작성 및 추가 채널 흐름도 완료했다.
- 지수: 모바일 저장 실패·언어 전환 취소 후 입력 보존, 재저장 및 게시 기록 흐름이 유지됐다.
- 캡처 화면에서 문서 가로 넘침과 처리되지 않은 브라우저 JavaScript 오류가 관찰되지 않았다.

증거: [모델 사전 안내](minseo-model-setup.png), [한국어 검토 진입과 메뉴 배지](alex-review-entry.png), [모바일 저장 실패 복구](jisu-save-error.png).

생성 문장은 모의 응답이며 외부 모델·실제 SNS 게시·운영 환경은 이번 재검증 범위에 포함하지 않았다. 변경은 로컬 작업 트리에 있으며 커밋·머지·배포하지 않았다. 실행 방법은 [최초 평가 보고서](../REPORT.md)를 참고한다.

## 추가 점검 후 수정

- 목록의 ‘초안 준비’, 상세의 ‘다시 분석하기’와 ‘그래도 초안 쓰기’에서 모델 설정 확인을 추가했다. 설정 조회 실패·미완료 또는 키 미설정이면 요청을 보내지 않는다. ‘그래도 초안 쓰기’는 이 확인 전에 판단 상태를 변경하지 않는다.
- 목록의 모델 관련 오류는 연결 관리 대신 모델 설정으로 안내한다. 조회 실패에는 설정 재조회 버튼을 제공한다.
- 상세의 설정 조회 실패 시 기존 초안에서 채널·언어를 선택하고 오류 및 재조회 버튼을 표시한다. 설정을 모르는 상태를 ‘채널 미설정’으로 잘못 안내하지 않는다.
- 글감 간 이동 시 이전 글감 데이터로 새 글감의 기본 언어를 초기화하지 않도록 ID를 확인한다.
- 설정 오류 복구 및 생성 요청 방지 회귀 테스트 5개를 추가했다. 모바일 실제 브라우저에서도 설정 조회 요청 실패 → 기존 초안 표시 → 설정 재조회 성공을 확인했다. [화면 증거](jisu-settings-error.png)

타입 검사·린트·전체 377개 테스트·빌드 및 확장한 15단계 페르소나 시나리오가 통과했다. 로컬 수정이며 아직 머지·배포하지 않았다.
