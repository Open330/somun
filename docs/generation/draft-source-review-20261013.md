# 문장과 원자료 대조

초안의 형식 검사 통과만으로 사실이 맞는지 알 수 없다. 기존 글감 상세의 원자료는 초안과 떨어져 있어 문장을 확인하는 과정이 번거로웠다.

초안 안에 `문장과 원자료 대조`를 추가했다. 제목·본문 문장을 선택하고 글감에 저장된 README, 릴리스 노트, PR·커밋 제목과 수집 당시 수치를 검색한다. 선택한 문장은 원자료 옆에 표시하며 검색어를 강조한다. 수정 중에는 현재 입력을, 버전 선택 시에는 해당 버전의 문장을 보여준다.

검색은 원문 표현의 부분 문자열 검색이다. 자동 의미 대조나 사실 확인 완료 표시를 제공하지 않는다. 생성된 highlights와 에이전트 요약을 원문 근거로 사용하지 않는다. 자료가 없거나 검색 결과가 없으면 원문 확인과 전체 자료 복귀 방법을 안내한다. 저장된 자료는 생성 당시 자료와 다를 수 있으며 PR·커밋 제목만으로 세부 동작을 확정할 수 없음을 표시한다.

운영 muxa 초안의 긴 릴리스 URL이 모바일 미리보기 밖으로 넘치는 문제도 확인했다. 미리보기와 텍스트 본문에서 긴 문자열이 줄바꿈되도록 수정했다.

변경은 기존 글감 상세 응답을 사용하는 화면 기능이다. 생성 프롬프트와 게시 동작은 변경하지 않는다.

검증: 원문 검색·강조, 번역 문장과의 수동 대조, 중복 릴리스 노트 제외, 생성 요약 제외, 자료 부재, 원문 링크의 프로토콜 제한, 수정 후 선택 무효화, 수집 수치 0과 미수집 수치 구분을 테스트한다. 운영에서는 기존 GitHub 계정과 Google 계정의 초안을 PC·모바일로 열고 검색, 이전 판 조회, 저장하지 않은 수정·취소를 확인한다. 계정별 소스·설정·소재·초안·게시 기록 보존도 대조한다.

이 검증은 검토 기능의 동작 확인이며, 사람의 검토 시간 감소나 신규 생성 품질 향상을 입증하지 않는다.
