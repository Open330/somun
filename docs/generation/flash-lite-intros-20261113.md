# 무료 flash-lite만으로 첫 소개 초안 만들기 — 회차 기록 (2026-11-12~14)

## 목표와 측정 방법

- 목표: 초안 생성 경로 전체를 무료 `gemini-3.5-flash-lite`만으로 돌립니다. 첫 소개 1개당 호출은 12회 이하, 유료 호출은 0회입니다. 생성본 10개 중 8개 이상이 "그대로 게시 가능"이어야 합니다.
- 입력: 고정 스냅샷 DB(수집·프로필·판단 완료). 프로젝트 5개(Open330/tend, haejo, aas, barshelf, jiunbae/oh-my-prompt) × X 한국어·영어 = 초안 10개.
- 판정: 매 회차 같은 두 판정자(Opus 5.5, Codex)가 고정 점검표 C1~C7로 봅니다. 둘 다 모든 항목을 통과해야 통과입니다.
  - C1 사실
  - C2 핵심 기능
  - C3 전제(동작 환경)
  - C4 언어
  - C5 군더더기
  - C6 권유·과장·근거 없는 수량
  - C7 형식(링크·길이)
- 같은 코드로 다시 생성해도 10개당 ±2~4개가 흔들립니다. 그래서 구성마다 3회(최대 30개)를 재고 합칩니다.
- 무료 쿼터 소진이나 503으로 초안이 만들어지지 않은 칸은 빼고, 실제로 생성된 초안("유효")만 셉니다.

## 변경별로 줄인 탈락

- **사실 힌트(r11)**:
  - 무엇: 원문에서 사실을 뽑고 인용 문자열로 검증한 뒤, 필수 전제어와 핵심 동작을 기존 프롬프트에 덧붙입니다.
  - 효과: 전제 누락(C3)이 15/52(29%)에서 1/27(4%)로 줄었습니다. 사실(C1)은 15%에서 4%로, 핵심(C2)은 15%에서 7%로 줄었습니다.
  - 그러나 통과율은 그대로였습니다. 상황을 까는 첫 문장이 늘어 C5가 10%에서 22%로 늘었습니다.
- **첫 문장 고정(r12)**:
  - 근거: 기준선과 r11의 초안 76개를 첫 문장에 제품명이 있는지로 나누면 통과율과 C5가 크게 갈렸습니다.
    - 제품명이 있을 때: 15개 중 10개 통과, C5 탈락 0개
    - 없을 때: 61개 중 20개 통과, C5 탈락 11개
  - 효과: C5가 6/27에서 1/28로 줄었습니다. 대신 남은 탈락이 한국어 C4로 몰렸습니다(13개 중 11개가 한국어).
  - 첫 문장에 제품명을 강제하는 lint는 넣지 않았습니다. 사용자가 직접 고친 c/82 Tend 소개가 상황 문장으로 시작해서, 사용자의 수정본을 탈락시키게 됩니다.
- **한국어 표현 전용 비평(r13)**:
  - 근거: 기존 비평(사실·형식·언어를 한꺼번에 봄)은 두 판정자가 C4로 떨어뜨린 한국어 초안 대부분을 "게시 가능"으로 답했습니다.
  - 무엇: 한국어 초안에만, 표현만 보는 비평을 따로 붙였습니다. 인용이 초안에 실제로 있는 지적만 편집 단계에 넘깁니다.
  - lint 보강: 수행·~하여·사용자의·가나/한자 섞임을 번역투 lint에 넣었습니다. 판정 모음에서 이 표현이 든 한국어 초안 34개 중 두 판정자를 모두 통과한 것은 1개였습니다.
  - 효과: r12와 비교하면 C4가 13/28(46%)에서 11/47(23%)로 줄었습니다. 통과율은 4.3에서 6.0으로 올랐습니다(r13r만 보면 5.3).

- **한국어 주어·행동 lint(r14)**:
  - 무엇: 제품이 주어인 문장이 독자의 행동(봅니다, 쓸 수 있습니다)으로 끝나거나, 제품 주제 아래 Claude·Codex가 행동하는 문장을 잡습니다.
  - 판정 모음 한국어 초안 147개에서 이 lint에 걸린 18개 중 1개만 통과했습니다(걸리지 않은 129개 중에서는 34개 통과).
  - 효과: 통과율은 r13r과 같은 5.3이었습니다. C2는 3에서 2로 줄었고, C4는 8에서 9로 같은 수준입니다. 걸리지 않은 꼴("aas는 … 계정을 나란히 사용합니다", "Claude와 Codex를 이용해")이 남았습니다.
- **선택(오프라인 시험)**:
  - 근거: 같은 구성 3회의 완성 초안 중 하나라도 통과한 칸이 r13r은 9/10, r14는 10/10이었습니다. 생성 결과 안에 통과본은 거의 있고, 고르는 단계가 병목입니다.
  - 무엇: flash-lite 비평 지적 수 + 한국어 비평 지적 수 + lint 탈락 수×2를 점수로 삼아 가장 낮은 초안을 골랐습니다.
  - 효과: 두 묶음 모두 7/10이었습니다. 하나를 무작위로 고를 때의 기대값은 5.3입니다.
  - 한계: 완성 초안 3개를 만들면 소개 하나에 호출이 약 20회로, 상한 12회를 넘습니다.

## 버린 것

- **후보 여러 개 + 쌍 비교 선택(r10)**: flash-lite의 쌍 비교 정확도가 판정 결과 대비 55%였습니다. 후보 안에 통과본이 있던 초안이 7/10이었는데도 선택 결과는 4/10이었습니다.
- **번역투 lint의 해당·나란히·시키·", 그리고"**: 판정 모음에서 통과한 초안까지 떨어뜨렸습니다. '이동시키다'도 이 표현이 든 초안 17개 중 5개가 통과해 lint에 넣지 않고 비평에 맡겼습니다.
