# Dogfooding 후 초안 품질 개선 — 2026-10-12

## 관찰과 변경

Threads의 해요체·두 문장·링크 제외를 모두 지켜도 “개발자에게 정말 편할 것 같아요”라는 근거 없는 평가가 생성됐다. 기존 수치·최상급 검사는 이를 놓쳐 자동 보정도 실행되지 않았다. 대화체는 작성자의 감상이나 사용자 효과를 지어낼 근거가 아니라는 지침을 추가했다.

`endorsement_need_review`는 한국어·영어의 일부 평가·추천 표현을 찾아 원문에 같은 진술이 있는지 확인한다. 낱말 하나가 원문에 있다는 이유로 평가 전체를 통과시키지 않는다. 독자에게 묻는 질문과 부정문은 구분한다. Threads의 `question_specificity`는 일반적인 제품 사용 여부·감상 질문을 작업 흐름 질문으로 바꾸도록 제안한다. 다른 개인 채널의 질문 정책은 바꾸지 않는다.

두 규칙은 기존 서버·로컬 워커의 최대 한 번 자동 보정에 연결했다. 실패하거나 새 위반이 생기면 원래 초안과 경고를 유지한다. 보정에는 채널 말투·구조·문장 예산을 다시 명시한다. 원래 일관된 한국어 말투를 바꾸거나 다른 근거 없는 평가로 바꾼 보정은 채택하지 않는다. 모든 사실을 억지로 넣는 대신 필요한 과업·변화와 근거 있는 진술을 보존한다.

첫 생성에서는 기능의 조건도 보존하도록 지시한다. 예를 들어 편집하고 **복사한** 초안에서 학습하는 기능을 편집만으로 학습한다고 소개하지 않도록 한다. 문장 예산 때문에 조건을 빠뜨려야 한다면 부차적인 기능 자체를 생략한다.

## 실행과 실패 기록

운영의 무료 게이트웨이 `gemini-3.5-flash-lite`로 같은 입력을 반복했다. 서비스 계정의 기존 한도와 사용량 경로를 사용했으며 평가 출력을 실제 게시하거나 복사 완료로 표시하지 않았다. 각 요청·응답 모델·프롬프트·실패를 별도 기록했다. 개인 계정과 프리셋을 포함한 원시 기록은 저장소에 커밋하지 않았다.

- 첫 비교: somun 소개 두 채널과 합성 자료 두 개, 사례마다 두 번씩 수정 전·후를 교차 실행해 총 16건. 같은 자동 검사로 수정 전 7/8, 수정 후 8/8이었지만 정성 검토에서는 각각 6/8·5/8이었다. 수정 후 일반적인 사용 여부 질문 두 건과 학습 조건 누락 한 건을 확인했다. 양쪽에서 평가 표현은 재발하지 않았으므로 이 비교로 발생률 감소를 주장하지 않는다.
- 보완 후 신규 생성 8건: 주요 내용·질문 기준에서 7/8. 남은 한 건은 제품을 써 봤는지 묻는 질문과 긴 도입문이었다. 이 사례를 질문 검사와 보정에 연결했다. 이 재평가는 이미 본 자료를 사용하므로 독립 보류 평가가 아니다.
- 보정 실험에서도 실패를 확인했다. 첫 평가 표현 보정은 감상을 제거했지만 합니다체로 바뀌었다. 질문 보정은 질문을 바꿔도 긴 도입문이 남았다. 최종 지침과 말투 보호 후 이 두 알려진 사례를 각각 한 번 호출해, 해요체의 짧은 기능 문장과 구체적인 작업 흐름 질문을 확인했다(2/2). 재작성 성공을 첫 생성 성공으로 계산하지 않는다.
- 최종 지침을 고정한 뒤 새 합성 자료 두 개를 두 번씩 생성했다. 라우트 검사와 CSV 필터·별도 파일 내보내기 사례 4/4가 자동 검사와 제공 근거에 대한 정성 검토를 통과했다. 원본 파일 보존 조건도 확인했다. 합성 자료의 프로젝트가 실재한다는 뜻은 아니다.

작은 표본과 Codex의 정성 검토이므로 일반 서비스 성공률, 사람의 시간 절약, 사용자 선호를 입증하지 않는다. 실제 계정의 운영 재검증은 배포 후 별도 기록한다.

## 재현 가능한 회귀 검사

```sh
npm run experiment -- run --config experiments/grounded-voice-replay.json
npm test
npm run typecheck
npm run lint
npm run format:check
npm run build
```

재생 사례는 알려진 실패의 회귀 검사다. `historical` 0/1, `corrected` 1/1이며 모델 호출은 없다. 저장된 출력의 재검사를 새 모델 생성이나 독립 표본으로 집계하지 않는다.

## 적용 범위와 한계

새 검사는 제한된 표현 패턴과 문장 대조를 사용한다. 모든 비수치 주장, 의미가 같은 의역, 질문의 적합성, 한국어의 자연스러움을 판정하는 의미 검증기가 아니다. 정당한 평가의 의역에도 확인 경고가 생길 수 있다. 경고가 없다는 사실은 사실 정확성이나 게시 가능성을 보장하지 않는다.

새 운영 의존성, DB 마이그레이션, 자동 게시, 추가 심사 모델은 도입하지 않았다. 문제가 감지됐을 때만 기존 1회 보정 호출이 추가될 수 있으며 기존 한도·사용량 정책을 따른다.
