# 품질 실험 결과 — 2026-09-22

**현재의 ‘간결하게 작성’ 지시를 기본값으로 채택할 근거는 부족하다.** 이번 표본에서는 글은 짧아졌지만 한국어 결과에서 필수 변경이 누락됐다. 자동 검사는 이 누락을 잡았으나 한국어 번역의 자연스러움은 잡지 못했다.

## 실행 범위

- `npm test`: 25개 파일, 126개 테스트 통과.
- 무과금 회귀: 정상 표본 6/6 통과, 의도적 오류 표본 6/6 탐지.
- 과거 결과 재검사: 수정 전 0/2 통과, 수정 후 2/2 통과. 이미 알려진 회귀 사례이며 독립 검증 세트는 아니다.
- 실제 생성: 동일한 Vite v8.3.0 자료, Show HN 영어·Show GN 한국어, 기본/간결 지시, 조건마다 2회 반복.
- 모델별 8건씩 총 16건 요청. 각 모델 실험을 별도 파일로 보존했다. 운영 DB·제품 기본 설정·외부 게시에는 반영하지 않았다.

생산용 draftPrompt를 사용하되 개인 문체·프로필·학습 예시는 로드하지 않았다. 실험기는 단일 키와 지정 모델을 사용하고 Gemini 모델 대체·키 순환을 하지 않는다. 따라서 아래 호출 결과를 운영 파이프라인 전체의 성공률로 일반화할 수 없다.

## 모델 호출

`gemini-3.7-flash`: 기본 0/4, 간결 0/4 생성 성공. HTTP 503 6건, 429 2건이다. **출력이 없으므로 품질 비교 불가**다. 실패 응답 시간을 빠른 생성 시간으로 해석하지 않았다.

별도 실행한 `gemini-3.5-flash-lite`는 요청한 모델 그대로 8/8 생성에 성공했다.

시간은 네트워크와 모델 응답 전체를 포함하며 첫 토큰 시간은 아니다. 반복 수가 적어 시간 차이의 원인이나 통계적 우열을 판단하지 않는다.

## 내용 대조 — AI 검토

검토자는 Codex(AI)다. 평가자에게 완전히 가린 독립 실험이나 실제 사용자 평가가 아니다. 모델/조건 정보 일부를 알고 진행했으며 사람 점수와 수정 시간은 입력하지 않았다.

1. **간결한 한국어 결과 두 건 모두 필수 사실이 빠졌다.** `node_modules` 경로 세그먼트 판정 변경이 없어 사례의 `required:node_modules` 검사에 실패했다. 원문 대조에서는 프록시 컨텍스트 매처의 사전 컴파일 변경도 함께 빠져, 네 가지 변경 중 두 가지만 남은 것을 확인했다. 후자는 현재 자동 기대 조건에 등록되지 않은 추가 관찰이다.
2. **한국어 결과 네 건 모두 문장 다듬기가 필요했다.** `code frame positions`, `line endings`, `path segments` 등을 그대로 혼용했다. 두 건에는 `settling`을 ‘정산’으로 옮긴 표현이 있어 개발 문맥에서 뜻이 모호했다. 해당 검사기에는 번역 품질을 판단하는 규칙이 없다.
3. **기본 영어 결과는 사실을 보존했지만 불필요한 설명이 있었다.** 한 결과의 ‘build performance during server operations’는 원문에서 나뉜 빌드/서버 항목을 혼동할 수 있게 요약했다. 간결 영어 결과는 네 변경을 유지하면서 이 부연을 줄였다.
4. 생성된 여덟 결과에서 근거 없는 새 수치나 명시적인 작성자의 개인 경험은 관찰하지 않았다. 이는 이 표본에 대한 관찰이며 일반적인 환각 부재의 증거는 아니다.

[개별 AI 검토 기록](agent-review.json)에 결과 식별자와 의견을 남겼다. `needsEditing: false`는 이번 텍스트 대조에서 뚜렷한 수정 항목을 찾지 못했다는 의미이며 플랫폼 게시 자격·링크 검증·사용자 게시 의향을 인증하는 값이 아니다.

## 다음 결정

- 기본 지시는 유지하고, 현재 간결 지시는 기본값으로 적용하지 않는다. ‘짧게 쓰기’와 함께 반드시 남길 사실을 지정하는 조건을 다음 실험으로 비교한다.
- 사례의 필수 사실 목록에 프록시 사전 컴파일도 넣을지 정하고, 단순 키워드 보존과 의미 보존을 나누어 검사한다. 이번 결과를 낸 기대 조건을 사후 수정하지는 않았다.
- 한국어 기술 용어 처리 조건을 별도 실험한다. 원문 용어 보존과 자연스러운 한국어 설명의 균형을 실제 사용자가 평가해야 한다.
- 503/429는 생성 품질과 분리해 가용성 결과로 남긴다. 재시도·키 순환이 있는 운영 경로의 복구율은 별도 테스트가 필요하다.

이 실험은 릴리스 자료 한 건에 대한 소규모 탐색이다. 다른 프로젝트·변경 유형·언어에 대한 우열, 실사용자의 시간 절약, 수정 없이 게시 가능한 비율은 결론 내리지 않는다.
