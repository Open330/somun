# 소문 브랜드

> 2026-09-21. 로고는 이 문서에서 나온다. 문서 없이 로고를 고치지 않는다.

## 1. 무엇인가

소문은 만드는 속도보다 알리는 속도가 느린 개발자를 위한 PR 도우미다.
저장소와 작업 세션을 지켜보다가, 알릴 만한 것이 생겼을 때만 채널별 초안을 건넨다.
대신 올리지 않고, 없는 숫자를 지어내지 않는다.

## 2. 무엇이 아닌가

- 확성기가 아니다. 소리를 키우는 도구가 아니라 고를 것을 고르는 도구다.
- 생성기가 아니다. 커밋을 트윗으로 바꾸지 않는다. 사실은 시스템이, 목소리는 사람이.
- 응원단이 아니다. "이번 주는 알릴 게 없다"가 정상 답이다.

## 3. 성격

| 이렇다 | 이렇지 않다 |
|---|---|
| 조용하다 | 요란하다 |
| 정확하다 | 그럴듯하다 |
| 편집자다 | 마케터다 |
| 절제한다 | 부풀린다 |

한 줄: **지어내지 않는 편집자.**

## 4. 상징 — 캐럿과 점

이름 **소문**의 첫 자모 **ㅅ**이 상징이다. 세 가지 뜻이 한 형태에 겹친다.

1. **사람(人)** — 마주 서서 말을 건네는 두 획. 소문은 입에서 입으로 간다.
2. **캐럿(^)** — 교정지에서 "여기에 넣어라"를 뜻하는 편집 표식. 소문의 정체성은 편집자다.
3. **갈래** — 한 점에서 두 갈래로 퍼지는 모양. 소문이 번지는 길.

캐럿 아래에 **점 하나**를 둔다. 초안에 들어가는 "사실 하나, 숫자 하나"다.
마크는 이 둘, 획 두 개와 점 하나로 끝난다. 더하지 않는다.

## 5. 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| 잉크 (Ink) | `#0F6F5C` → `#0A4F42` | 마크 획, 주 색. 교정지의 녹색 잉크 |
| 사실 (Fact) | `#E5A33C` | 마크의 점, 점수. 한 번만 쓰는 강조 |
| 종이 (Paper) | `#F4F6F8` / `#0E1216` | 밝은·어두운 바탕 |

녹색은 "교정 잉크"에서 왔다. 빨간 펜이 아니라 녹색 펜인 이유는, 소문은 틀린 것을 지우는 쪽이 아니라 맞는 것을 골라 넣는 쪽이기 때문이다.

## 6. 글자

- 워드마크 `소문`: Noto Sans KR 700. 자간 -2%.
- 로마자 `somun`: Sora 600, 소문자, 자간 +8%. 워드마크 아래나 옆에 작게.
- 본문 UI: Noto Sans KR / Sora / JetBrains Mono (디자인 토큰과 같다).

## 7. 결합과 사용

- **마크 단독**: 투명 배경 PNG/SVG. 앱 아이콘, 파비콘, 아바타.
- **타일**: 둥근 사각형 잉크 바탕에 종이색 마크. 앱 스토어·OS 아이콘처럼 배경이 필요한 곳.
- **가로 결합**: 마크 + `소문` + `somun`. 랜딩, 문서 머리.
- 최소 크기 16px. 그 아래에서는 점을 빼고 캐럿만 쓴다.
- 마크를 기울이거나, 그림자·광택을 더하거나, 다른 색으로 칠하지 않는다. 단색(잉크 또는 종이)으로만 쓴다.

## 8. 파일

| 파일 | 용도 |
|---|---|
| `mark.svg` | 마크 원본 (잉크색, 투명) |
| `mark-paper.svg` | 마크 (종이색, 어두운 배경·타일용) |
| `icon-1024.png` | 앱 아이콘, 투명 배경 RGBA |
| `tile-1024.png` | 타일 아이콘 (배경 있음) |
| `lockup.svg` | 가로 결합 |
| `sheet.png` | 브랜드 시트 (검토용) |
