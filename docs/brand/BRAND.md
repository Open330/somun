# 소문 브랜드

> 2026-09-21. 로고는 이 문서에서 나온다. 문서 없이 로고를 고치지 않는다.

## 1. 무엇인가

소문은 만드는 속도보다 알리는 속도가 느린 개발자를 위한 PR 도우미다.
저장소와 작업 세션을 지켜보다가, 알릴 만한 것이 생겼을 때만 채널별 초안을 건넨다.
대신 올리지 않고, 없는 숫자를 지어내지 않는다.

## 2. 무엇이 아닌가

- 확성기가 아니다. 소리를 키우는 도구가 아니라 고를 것을 고르는 도구다.
- 생성기가 아니다. 커밋을 트윗으로 바꾸지 않는다. 사실은 시스템이, 목소리는 사람이.
- 응원단이 아니다. "이번 주는 알릴 게 없다"가 정상 답이다.

## 3. 성격

| 이렇다 | 이렇지 않다 |
|---|---|
| 조용하다 | 요란하다 |
| 정확하다 | 그럴듯하다 |
| 편집자다 | 마케터다 |
| 절제한다 | 부풀린다 |

한 줄: **지어내지 않는 편집자.**

## 4. 상징 — ㅅ, 그리고 ㅁ

이름 **소문**의 두 자모가 뜻을 나눠 갖는다.

- **ㅅ** — 말. 사람(人)이 마주 서서 말을 건네는 두 획, 교정지의 캐럿(^), 퍼지는 갈래.
- **ㅁ** — 만든 것. 상자, 저장소, 결과물.

마크는 읽는 순서대로 ㅅ이 왼쪽, ㅁ이 오른쪽에 있고, **ㅅ의 오른획이 ㅁ의 왼쪽 위로 걸쳐 들어온다.** 만든 것에서 말이 번진다.
ㅁ 안으로 들어온 ㅅ은 종이색으로 반전해 한 톤에서 두 형태가 짜인다. 장식은 없다.

### 구축 (활자 방식)

획을 선으로 긋지 않고 면으로 짠다. 이 구축은 람다(λ)와 같은 원리이고, 획 순서만 ㅅ이다.

| 항목 | 값 |
|---|---|
| 격자 | 1024 |
| 획 각도 | 수직 기준 30° |
| 획 두께 | 118 (수직 방향), 끝은 수평으로 자름 |
| 오른획 분기 | 왼획 높이의 30% 지점 |
| ㅁ | 464×464, 모서리 72 |
| 밑선 | ㅅ과 ㅁ이 800을 공유 |

버린 방향과 이유: 둥근 끝 선 획(마커 낙서처럼 보임), 캐럿+점(장식), S 리플(장식·광택), 워드마크 "소"(글자 하나는 상징이 못 됨), 각진 ㅁ 모서리 28(소형에서 아이콘 틀과 겹침).

## 5. 색

| 이름 | 값 | 쓰임 |
|---|---|---|
| 소나무 (Pine) | `#123F3A` | 마크와 주 색. 채도를 낮춘 짙은 녹색. 교정 잉크 |
| 먹 (Ink) | `#15191E` | 단색 변주(`mark-ink.svg`), 본문 글자 |
| 종이 (Paper) | `#F3F4F2` | 밝은 바탕, 마크의 반전 부분 |
| 밤 (Night) | `#0E1216` | 어두운 바탕 |
| 사실 (Fact) | `#E5A33C` | UI의 점수·강조에만. 마크에는 쓰지 않는다 |

녹색이 교정 잉크인 이유: 빨간 펜은 지우고, 녹색 펜은 골라 넣는다. 소문은 후자다.

## 6. 글자

- 워드마크 `소문`: Noto Sans KR 700. 자간 -2%.
- 로마자 `somun`: Sora 600, 소문자, 자간 +8%. 워드마크 아래나 옆에 작게.
- 본문 UI: Noto Sans KR / Sora / JetBrains Mono (디자인 토큰과 같다).

## 7. 결합과 사용

- **마크 단독**: 투명 배경 PNG/SVG. 앱 아이콘, 파비콘, 아바타.
- **타일**: 둥근 사각형 잉크 바탕에 종이색 마크. 앱 스토어·OS 아이콘처럼 배경이 필요한 곳.
- **가로 결합**: 마크 + `소문` + `somun`. 랜딩, 문서 머리.
- 최소 크기 16px. 반전 부분이 뭉개지면 타일 버전을 쓴다.
- 마크를 기울이거나, 그림자·광택을 더하거나, 다른 색으로 칠하지 않는다. 단색(잉크 또는 종이)으로만 쓴다.

## 8. 파일

| 파일 | 용도 |
|---|---|

| `mark-ink.svg` | 단색 먹 변주 |

| `tile-1024.png` | 타일 아이콘 (배경 있음) |
| `lockup.svg` | 가로 결합 |
| `sheet.png` | 브랜드 시트 (검토용) |
